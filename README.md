# Web Agent Resume Builder

A local-first, human-supervised job-application preparation tool.

## Safety boundary

This software can validate verified candidate evidence, build local retrieval indexes, inspect job-application forms, prepare drafts, create review artifacts, and optionally fill explicitly approved low-risk fields.

It cannot and will not submit an application.

`NO APPLICATION HAS BEEN SUBMITTED. HUMAN REVIEW AND MANUAL SUBMISSION ARE REQUIRED.`
